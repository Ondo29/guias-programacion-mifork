#include <stdio.h>
#include <stdlib.h>

typedef struct {
    void **data;      // array de punteros genéricos
    size_t size;      // elementos usados
    size_t capacity;  // capacidad total
} Vector;

Vector* vector_create(size_t capacity) {
    Vector* v = malloc(sizeof(Vector));
    v->data = malloc(sizeof(void*) * capacity);
    v->size = 0;
    v->capacity = capacity;
    return v;
}

2. Brevemente, ¿Qué significa la programación genérica? ¿Es el ejemplo anterior un ejemplo básico de programación genérica?

Respuesta: 

La programación genérica es un estilo de programación que permite escribir código que funciona con cualquier tipo de dato, sin tener que duplicarlo para cada tipo específico. En lugar de fijar tipos concretos (como int, double, String), se usan parámetros de tipo o mecanismos equivalentes para que el mismo código sea reutilizable.
